# Подробный гид по созданию простого приложения для управления заказами на Python

Представь, что ты строишь домик: каждый кирпичик (строка кода) имеет своё место, и мы объясним, зачем он нужен.

### Что такое это приложение?
Это маленькая программа, как блокнот на компьютере, но с кнопками и окнами. Она помогает хранить "заказы" — например, "10 яблок" или "Книга по Python". Ты можешь добавлять, смотреть, менять или удалять их. Данные сохраняются в **базе данных** (как большой ящик с карточками, где ничего не потеряется, даже если выключишь компьютер).

**Почему это круто для новичков?**
- **Tkinter** — это "волшебная палочка" Python для создания окон и кнопок. Без неё программа была бы просто текстом в консоли.
- **PostgreSQL** — база данных, как Google Sheets, но для твоего компьютера. Она хранит информацию надёжно.
- **Peewee** — помощник, который упрощает работу с базой (как библиотекарь, который сам находит книги).

**Что тебе нужно, чтобы запустить?**
1. Установи Python (с сайта python.org).
2. Установи библиотеки: открой командную строку (cmd в Windows) и напиши `pip install peewee python-dotenv psycopg2`.
3. Установи PostgreSQL (бесплатно с postgresql.org) и создай базу данных (мы объясним).
4. Создай папку `project` и файлы внутри (скопируй код из гида).

Проект состоит из трёх файлов: `db.py` (соединение с ящиком), `models.py` (описание карточек) и `main.py` (сам домик с комнатами). Давай разберём каждый!

## 1. Файл `db.py`: Соединяемся с базой данных
**Теория на пальцах:** База данных — это как большой файл, где хранятся данные. Чтобы Python мог с ней "говорить", нужен "мостик" — подключение. Мы используем файл `.env`, чтобы спрятать секреты (логин, пароль), как в игре с паролями.

Создай файл `db.py` и скопируй этот код. А рядом создай `.env` с твоими данными (пример ниже).

```python
# Строка 1: Импортируем инструмент для работы с PostgreSQL
from peewee import PostgresqlDatabase
```
- **Что это?** `from peewee import ...` — как "возьми из коробки инструмент". Peewee — библиотека, которая помогает Python общаться с базой. `PostgresqlDatabase` — специальный инструмент для PostgreSQL (как ключ для конкретного замка).
- **Теория:** В Python `import` — это как приглашение друга на вечеринку. Без него код не знает, что такое `PostgresqlDatabase`.

```python
# Строка 2: Импортируем помощника для чтения секретов
from dotenv import load_dotenv
```
- **Что это?** `dotenv` — библиотека, которая читает файл `.env` (как открывает конверт с письмом). `load_dotenv` — команда "загрузи секреты".
- **Теория:** Секреты (пароли) не пишут в код, чтобы никто не украл. `.env` — скрытый файл только для тебя.

```python
# Строка 3: Импортируем os для работы с окружением
import os
```
- **Что это?** `os` — встроенный "шпион" Python, который читает переменные (как `os.getenv` — "дай значение по имени").
- **Теория:** `import os` — базовый импорт, как "включи свет" в комнате.

```python
# Строки 5-6: Загружаем секреты из .env
load_dotenv()
```
- **Что это?** Запускает загрузку. Теперь секреты доступны.
- **Теория:** Это как "открой дверь" — после этого код может использовать `os.getenv`.

```python
# Строки 8-15: Создаём мостик к базе
db = PostgresqlDatabase(
    os.getenv("DB_NAME"),      # Имя базы данных
    user=os.getenv("DB_USER"), # Имя пользователя
    password=os.getenv("DB_PASSWORD"), # Пароль
    host=os.getenv("DB_HOST"), # Адрес сервера базы данных
    port=int(os.getenv("DB_PORT"))     # Порт (обычно 5432)
)
```
- **Что это?** `db = ...` — создаёт переменную `db` (как имя твоего мостика). В скобках — настройки: имя базы (`DB_NAME`), логин (`DB_USER`) и т.д. `os.getenv("DB_NAME")` — берёт значение из `.env`. `int(...)` — превращает текст в число (порт — это число, как дом на улице).
- **Теория:** Переменная — как коробка с ярлыком: `db` хранит мостик. `PostgresqlDatabase` — конструктор, как рецепт: "смешай ингредиенты и получи объект".
- **Пример .env (создай сам!):**
  ```
  DB_NAME=myorders
  DB_USER=postgres
  DB_PASSWORD=12345
  DB_HOST=localhost
  DB_PORT=5432
  ```
  (Замени на свои. В PostgreSQL создай базу `myorders` через pgAdmin или команду `createdb myorders`.)

**Что делает весь файл?** Готовит мостик. Без него данные не сохранятся!

## 2. Файл `models.py`: Описываем, как выглядят заказы
**Теория на пальцах:** База — это таблица, как школьный журнал. Каждая строка — заказ (карточка). Мы говорим: "В карточке должно быть название (текст) и количество (число)". Peewee создаст таблицу автоматически.

Создай `models.py`.

```python
# Строка 1-2: Импортируем инструменты для создания модели
from peewee import Model, CharField, IntegerField
```
- **Что это?** `Model` — базовый "шаблон" для таблицы. `CharField` — для текста (как строка в тетради). `IntegerField` — для целых чисел (1, 2, 10).
- **Теория:** Импорты — как набор инструментов: Model — каркас, поля — ячейки.

```python
# Строка 3: Импортируем мостик из db.py
from db import db
```
- **Что это?** Берём `db` оттуда, чтобы модель знала, к какой базе подключаться.
- **Теория:** Файлы общаются через `import` — как письма между друзьями.

```python
# Строки 5-6: Создаём класс Order (шаблон таблицы)
class Order(Model):
```
- **Что это?** `class` — как чертёж дома. `Order` — имя класса (таблица называется "Order"). Всё внутри — описание.
- **Теория:** Класс — рецепт: "Чтобы сделать заказ, возьми Model и добавь поля". Peewee превратит это в настоящую таблицу в базе.

```python
# Строка 7: Поле для названия (текст)
    name = CharField()      # Название заказа (текст)
```
- **Что это?** `name` — имя поля. `CharField()` — создаёт колонку для текста (до 255 символов по умолчанию).
- **Теория:** Поля — как столбцы в таблице Excel. Без скобок `()` поле не создастся.

```python
# Строка 8: Поле для количества (число)
    quantity = IntegerField()  # Количество (число)
```
- **Что это?** Аналогично: `quantity` — колонка для чисел (целых, без запятой).
- **Теория:** `IntegerField` проверяет: "Это число? Ок!" Если нет — ошибка.

```python
# Строки 10-11: Настройки модели
    class Meta:
        database = db       # Привязка к базе данных
```
- **Что это?** `class Meta` — "секретные настройки" (meta = о модели). `database = db` — "прикрепи к нашему мостику".
- **Теория:** Meta — как инструкция на коробке: "Используй эту базу".

```python
# Строки 13-15: Подключаемся и создаём таблицу
db.connect()
db.create_tables([Order])
```
- **Что это?** `db.connect()` — "включи мостик". `db.create_tables([Order])` — "построй таблицу по чертежу Order, если её нет".
- **Теория:** Это запускается при импорте файла. `[Order]` — список (даже один элемент в скобках). Если таблица есть — ничего не сломается.

**Что делает весь файл?** Рисует таблицу. Теперь база знает: каждый заказ — это {id (авто), name (текст), quantity (число)}.

## 3. Файл `main.py`: Строим окошко и кнопки
**Теория на пальцах:** Tkinter — как конструктор Lego для окон. Мы создаём окно, добавляем ярлыки (текст), поля (для ввода), список (для показа) и кнопки (действия). Функции — как мини-программы: "когда нажмут кнопку, сделай это".

Создай `main.py`. Запусти его командой `python main.py` — увидишь окно!

```python
# Строки 1-2: Импортируем Tkinter и окошко ошибок
import tkinter as tk
from tkinter import messagebox
```
- **Что это?** `tkinter as tk` — основной импорт (as tk — короткое имя). `messagebox` — для попапов ("Ошибка!").
- **Теория:** Tkinter — GUI (графический интерфейс). `import` берёт всё нужное.

```python
# Строка 3: Импортируем модель Order
from models import Order
```
- **Что это?** Берём `Order` из models.py, чтобы читать/писать в базу.
- **Теория:** Связь файлов — ключ к большому проекту.

```python
# Строки 5-7: Создаём главное окно
root = tk.Tk()
root.title("Приложение заказов")
root.geometry("400x400")
```
- **Что это?** `tk.Tk()` — создаёт пустое окно (root = корень). `title` — заголовок. `geometry` — размер (400 пикселей шириной, 400 высотой).
- **Теория:** Окно — холст. Без `root.mainloop()` в конце оно закроется сразу.

```python
# Строки 9-12: Добавляем ярлык и поле для названия
name_label = tk.Label(root, text="Название заказа:")
name_label.pack()
name_entry = tk.Entry(root)
name_entry.pack()
```
- **Что это?** `tk.Label` — текст на экране (parent=root — где разместить). `pack()` — "положи в окно" (автоматически вниз). `tk.Entry` — поле ввода (как строчка в форме).
- **Теория:** `pack()` — простой менеджер: элементы ставятся друг под друга. Label — статичный текст.

```python
# Строки 13-16: То же для количества
quantity_label = tk.Label(root, text="Количество:")
quantity_label.pack()
quantity_entry = tk.Entry(root)
quantity_entry.pack()
```
- **Что это?** Аналогично: ярлык + поле. Теперь у нас форма ввода.
- **Теория:** Повторение — основа: копируй и меняй.

```python
# Строки 18-19: Список для показа заказов
orders_listbox = tk.Listbox(root, width=50)
orders_listbox.pack(pady=10)
```
- **Что это?** `tk.Listbox` — список (как меню в игре). `width=50` — ширина. `pady=10` — отступ снизу/сверху.
- **Теория:** Listbox хранит строки. `insert` добавляет, `delete` убирает.

```python
# Строки 21-30: Функция refresh_list() — обновить список
def refresh_list():
    """
    Обновление списка заказов в окне приложения.
    
    - Очищает список заказов в интерфейсе.
    - Загружает все записи из базы данных.
    - Показывает ID, название и количество каждого заказа.
    """
    orders_listbox.delete(0, tk.END)
    for order in Order.select():
        orders_listbox.insert(tk.END, f"{order.id}. {order.name} — {order.quantity}")
```
- **Что это?** `def` — определяет функцию (как рецепт: имя + скобки). Докстринг ("""...""") — объяснение для людей.
  - `delete(0, tk.END)` — очисти от начала до конца.
  - `Order.select()` — "возьми все заказы" (Peewee-волшебство).
  - `for order in ...` — цикл: для каждого заказа...
  - `insert(tk.END, f"...")` — добавь строку в конец. `f"{...}"` — форматирование (вставь переменные).
- **Теория:** Функция — мини-программа, вызывается по имени. Цикл `for` — как "для каждого яблока в корзине". `tk.END` — "конец списка".

```python
# Строки 32-47: Функция add_order() — добавить
def add_order():
    """
    Добавление нового заказа в базу данных.
    
    - Берёт данные из полей ввода.
    - Проверяет, что поля заполнены.
    - Преобразует количество в число.
    - Создаёт новый заказ в базе.
    - Обновляет список заказов на экране.
    - Очищает поля для ввода.
    """
    name = name_entry.get()
    quantity = quantity_entry.get()
    if not name or not quantity:
        messagebox.showwarning("Ошибка", "Заполните все поля")
        return
    try:
        quantity = int(quantity)
        Order.create(name=name, quantity=quantity)
        refresh_list()
        name_entry.delete(0, tk.END)
        quantity_entry.delete(0, tk.END)
    except ValueError:
        messagebox.showerror("Ошибка", "Количество должно быть числом")
```
- **Что это?** 
  - `get()` — возьми текст из поля.
  - `if not ...` — проверка: если пусто (`not` = нет), покажи warning и `return` (выход из функции).
  - `try: ... except:` — "попробуй": `int(quantity)` — в число. Если ошибка (ValueError — "не число"), покажи error.
  - `Order.create(...)` — создай запись (Peewee сохранит в базу).
  - `delete(0, tk.END)` — очисти поле.
- **Теория:** `if` — развилка: да/нет. `try-except` — страховка от ошибок (как "если упадёшь — подушка"). `return` — "стоп здесь".

```python
# Строки 49-64: Функция delete_order() — удалить
def delete_order():
    """
    Удаление выбранного заказа из базы данных.
    
    - Проверяет, что выбран элемент в списке.
    - Определяет ID заказа по выбранному элементу.
    - Удаляет запись из базы.
    - Обновляет список заказов.
    """
    selected = orders_listbox.curselection()
    if not selected:
        messagebox.showwarning("Ошибка", "Выберите заказ для удаления")
        return
    item_text = orders_listbox.get(selected[0])
    order_id = int(item_text.split(".")[0])
    order = Order.get_or_none(Order.id == order_id)
    if order:
        order.delete_instance()
        refresh_list()
```
- **Что это?** 
  - `curselection()` — верни номер выбранного (кортеж, [0] — первый).
  - `get(...)` — текст выбранного.
  - `split(".")` — разрежь по точке, [0] — ID, `int` — в число.
  - `Order.get_or_none(...)` — найди по ID (== — равно).
  - `delete_instance()` — удали.
- **Теория:** `split` — как ножницы по разделителю. Списки/кортежи — как мешки: [0] — первый элемент.

```python
# Строки 66-85: Функция update_order() — изменить
def update_order():
    """
    Изменение выбранного заказа.
    
    - Проверяет, что выбран элемент в списке.
    - Берёт новые значения из полей ввода.
    - Проверяет, что поля заполнены и количество — число.
    - Сохраняет изменения в базе.
    - Обновляет список заказов.
    """
    selected = orders_listbox.curselection()
    if not selected:
        messagebox.showwarning("Ошибка", "Выберите заказ для изменения")
        return
    name = name_entry.get()
    quantity = quantity_entry.get()
    if not name or not quantity:
        messagebox.showwarning("Ошибка", "Заполните все поля")
        return
    try:
        quantity = int(quantity)
        item_text = orders_listbox.get(selected[0])
        order_id = int(item_text.split(".")[0])
        order = Order.get_or_none(Order.id == order_id)
        if order:
            order.name = name
            order.quantity = quantity
            order.save()
            refresh_list()
    except ValueError:
        messagebox.showerror("Ошибка", "Количество должно быть числом")
```
- **Что это?** Похоже на add + delete: найди, измени поля (`order.name = ...`), `save()` — сохрани в базу.
- **Теория:** Объекты (order) — как живые: измени свойство и сохрани.

```python
# Строки 87-94: Создаём кнопки
add_button = tk.Button(root, text="Добавить", command=add_order)
add_button.pack()

update_button = tk.Button(root, text="Изменить", command=update_order)
update_button.pack()

delete_button = tk.Button(root, text="Удалить", command=delete_order)
delete_button.pack()

refresh_button = tk.Button(root, text="Обновить список", command=refresh_list)
refresh_button.pack(pady=5)
```
- **Что это?** `tk.Button` — кнопка. `text` — надпись. `command=функция` — "при клике запусти". `pack()` — размести.
- **Теория:** Кнопки — действия. Повторяй для каждой.

```python
# Строка 96: Загружаем список при старте
refresh_list()
```
- **Что это?** Вызов функции: покажи заказы сразу.
- **Теория:** Код выполняется сверху вниз — это запустится перед окном.

```python
# Строка 98: Запуск приложения
root.mainloop()
```
- **Что это?** "Запусти цикл": окно открыто, жди кликов. Без этого — мигнёт и закроется.
- **Теория:** mainloop — сердце GUI: слушает события (клики, ввод).

## Как запустить и экспериментировать?
1. Создай файлы, `.env` и базу.
2. Запусти `python main.py`.
3. Добавь заказ: "Яблоки", "5" → Добавить.
4. Выбери в списке, измени на "6" → Изменить.
5. Удали.

**Советы для школьников:**
- **Ошибки?** Читай: "NameError" — забыли import. "ValueError" — не число.
- **Улучши сам:** Добавь поле "цена" (FloatField в models). Или цвет кнопок (`bg="green"`).
- **Теория в действии:** Программирование — как пазл: строчки соединяются. Меняй одну — смотри, что сломается/улучшится.
